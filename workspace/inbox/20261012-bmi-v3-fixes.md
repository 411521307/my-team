## What to change / 改哪裡

Make these three fixes **in the v3 file**. This is a polish pass on v3, not a new version.

### 1. Translate the browser tab title

`<title>BMI Calculator 🧮 (v3)</title>` is frozen in English. Add a `pageTitle` key to each language in `I18N` and set `document.title` inside `applyLanguage()`:

- `en` → `BMI Calculator 🧮`
- `zh-Hant` → `BMI 計算器 🧮`
- `ja` → `BMI 計算機 🧮`

(The `(v3)` marker is only for our file naming — leave it out of the tab title.)

### 2. Translate the input placeholders

`placeholder="e.g. 170"` / `"e.g. 65"` stays English in every language. Give both inputs a `data-i18n-placeholder` attribute and set `.placeholder` in `applyLanguage()` — **do not** put placeholders in the `data-i18n` textContent mechanism, that would overwrite the wrong thing. Add `phHeight` / `phWeight` keys:

| lang | height placeholder | weight placeholder |
|---|---|---|
| `en` | `e.g. 170` | `e.g. 65` |
| `zh-Hant` | `例：170` | `例：65` |
| `ja` | `例：170` | `例：65` |

Clear the hard-coded `placeholder` attributes from the HTML so the JS is the single source of truth.

### 3. Make the Japanese table consistent with WHO thresholds

Your Japanese labels are 日本肥満学会 terms sitting under **WHO** numbers — the two systems disagree (JASSO calls BMI 25 "normal", WHO calls it overweight). Since the table header says `WHO 判定基準`, use WHO wording in Japanese:

- `catNormal`: `普通` → **`正常`**
- `catOverweight`: `肥満（1度）` → **`過体重`**

Leave `低体重` and `肥満` as they are — those already match WHO.
